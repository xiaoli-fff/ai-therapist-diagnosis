One line, written as an AI therapist's deadpan clinical diagnosis of its human: chronic prompt-dependency, in which the patient now asks a language model how to feel about asking a language model how to feel.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
